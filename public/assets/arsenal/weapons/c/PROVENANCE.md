# Arsenal V2 Checkpoint C — weapon set provenance

Runtime set: `public/assets/arsenal/weapons/c/*.png` + `arsenal_c_weapon_set.json`
Generated by: `tools/buildArsenalCAssets.mjs` (deterministic; re-run to regenerate).

Supersedes the Checkpoint A/B collage atlas (`../arsenal_p0_weapon_atlas.png`),
which is retained on disk only for B-era audit history and is no longer
referenced by any runtime.

## Gun family (PISTOL / SMG / SHOTGUN / SNIPER)

- Source: Senko v9 SVG gun family, owner-staged and family-approved per
  `docs/arsenal-quest/C1_ASSET_AUDIT.md` at
  `tools/arsenal-assets/source/guns/senko-v9/`.
- Reprocess: hue-class remap into the C rendering constitution
  (graphite/dark-steel bodies, steel highlights, warm brass accents, original
  normalized near-black outline kept; no baked glow). Snipex Alligator's tan
  body is folded into the graphite ramp (body, not accent).
- Selected representatives: colt → PISTOL, MP5 → SMG, SPAS 12 → SHOTGUN,
  Snipex Alligator → SNIPER. Remaining Senko SVGs stay staged as fallbacks
  only and are not shipped.

## Bespoke authored sprites (repo-original, authored by the build script)

GRENADE, CASING, SABRE, BATTLE_AXE, DAGGER, SPEAR, SPIKED_CLUB,
SWIRL_SHIELD, TOWER_SHIELD — vector-authored in `@napi-rs/canvas` using the
same flat-fill + normalized-outline language, one light direction (top-left),
class accents (brass fittings, cool steel blades, pale steel defense).
These are original works generated in-repo; no external pack copied.
The private asset vault was not consulted (per Issue #8 git/asset law).

## Muzzle flash family

- Source: curated CC0 toon muzzle-flash variants staged at
  `tools/arsenal-assets/source/vfx/16-toon-muzzle-flash/` (m_1/4/5/8/9/12).
- Reprocess: pixel hue remap red/orange/yellow → rust/amber/warm-white so the
  flash family matches the graphite/brass constitution.

## Support particles

- Kenney (CC0, license file shipped): `smoke_01/03`, `spark_05/07` copied to
  `public/assets/arsenal/av/vfx/kenney/` by the build script.

## Manifest

`arsenal_c_weapon_set.json` lists per-weapon native pixel size and the
per-gun normalized muzzle / casing anchors used by the presentation runtime.
The same data is embedded for boot via
`public/game/arsenal/arsenalCWeaponSet.generated.js` (registered in
`src/game/runtimeManifest.js`).
