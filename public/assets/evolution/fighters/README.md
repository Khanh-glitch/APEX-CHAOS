# Black Hole & Chrono combat art atlases

These 512×512 RGBA textures are art-directed crops of the project's existing Gold fighter and skill illustrations. A radial feather mask removes the hard rectangular card edge at arena scale. The original high-resolution art remains available under `public/assets/gold-ui/heroes/black_hole/` and `.../time/`.

Atlas slots:
- `black-hole/reactor-art.png`: illustrated reactor chassis/eyes/accretion core, animated beneath the orbital armor rig.
- `black-hole/wormhole-art.png`: two-mouth wormhole skill texture, mapped to the real A1 singularity.
- `black-hole/singularity-art.png`: black-hole aperture texture used by A1 and A2 escrow bloom.
- `chrono/astrolabe-art.png`: engraved brass/cyan tourbillon material for the animated Chrono rig and time-loop echoes.
- `chrono/loop-art.png`: Chrono's recorded volleys / echo skill artwork.
- `chrono/rewind-art.png`: counter-rotating rewind shutter artwork.
