APEX CHAOS — ARSENAL BATTLE (Windows, offline)

HOW TO PLAY
1. Extract this ZIP anywhere (the whole folder).
2. Double-click PLAY_WINDOWS.bat.
3. Your browser opens automatically once the local server is listening.
   (If it does not, open the printed http://localhost:<port>/?build=... URL.)
4. Choose Bot Battle or Local 1v1 from the product menu.
5. Keep the console window open while playing; close it to stop the server.

NOTES
- No Node, pnpm, npm, Python, Git, VS Code, or internet needed.
- The server uses built-in Windows PowerShell/.NET, picks a free localhost
  port each launch (never a fixed port), sends no-cache headers, and prints
  the exact build SHA (also in app\ARSENAL_BUILD_SHA.txt).
- You can launch several copies at once; each gets its own free port.
- T rematches after a KO; B/ESC exits the active battle.
