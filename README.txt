APEX CHAOS - ONE-CLICK PERFORMANCE DIAGNOSIS (WINDOWS)
=======================================================
1. Download this ONE GitHub branch ZIP while logged into your GitHub account.
2. Right-click the downloaded ZIP and choose "Extract All".
3. Double-click START-HERE.cmd in the extracted folder.

No Git installation, no six-part assembly, no Node installation, no terminal.
START-HERE automatically assembles and SHA-checks the package, extracts it,
downloads official Node.js if your PC needs it, and launches Chrome/Edge.
The Windows folder containing p0-diagnosis-latest.json opens after the run.
Send p0-diagnosis-latest.json back to ChatGPT.

Needs: Windows 10/11 x64, Chrome or Edge; internet once if Node is missing.
The game and personal browser profile are not modified.
This is a diagnostic, not a fix or a claimed FPS improvement.
