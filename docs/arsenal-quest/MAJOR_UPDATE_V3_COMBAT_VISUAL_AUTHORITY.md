# 2. GUN CRITICAL-HIT SYSTEM

Critical hits apply to GUNS only in V3.

No crit for:
- grenade;
- melee;
- shields;
- native fighter skills;
- heals.

## 2.1 Shared multiplier

Use one multiplier for every gun:

`CRIT_DAMAGE_MULTIPLIER = 1.60`

Do not create hidden per-gun crit multipliers.

This makes the amount multiplied comparable across guns as requested; gun identity is expressed primarily through crit CHANCE, not wildly different crit multipliers.

## 2.2 Roll granularity

Roll crit exactly ONCE per weapon attack activation/use sequence.

Examples:
- a SEMI activation with multiple scripted shots shares one crit result;
- one AUTO/BURST weapon-use sequence shares one result;
- one shotgun blast/auto-shot sequence shares one result across its pellets/shots;
- a precision activation shares one result across the attack sequence.

Do NOT independently crit every pellet.

The attack context stores `isCrit` so all damage from that attack is deterministic.

Use a dedicated injectable combat RNG stream or equivalent deterministic source.

Do NOT consume the spawn RNG stream for crit rolls; crit activity must not alter future pickup rarity/weapon selection.

For an Arsenal gun attack:
1. resolve the attack crit roll;
2. calculate scaled Arsenal base damage;
3. if crit, apply x1.60;
4. pass the final amount through existing shield/damage transaction logic;
5. popup/splatter/VFX receive explicit `isCrit` metadata.

A shield reducing damage does not erase the fact that the originating attack was critical; popup amount still shows REALIZED post-mitigation damage.

Log enough structured data to prove:
- weapon;
- chance;
- roll/result;
- base scaled amount;
- final realized amount.

# 3. DAMAGE NUMBER VISUAL LANGUAGE

The owner wants exactly three semantic number colors:

- normal damage = RED;
- critical damage = ORANGE;
- healing = GREEN.

MISS is not a number and may remain neutral slate/gray.

Use the existing canonical `damage1.png` glyph asset.

## 3.1 Exact colors

Normal:
- fill: **#FF3B30**
- hard dark edge: **#4A0B09**

Critical:
- fill: **#FF8A24**
- hard dark edge: **#5B2400**

Heal:
- fill: **#34D96B**
- hard dark edge: **#083D20**

MISS:
- neutral slate body with its existing readable light halo;
- do not introduce another colored damage category.

Do not use white, amber-heavy, rarity colors or victim colors for numerical damage.

## 3.2 Six non-linear size bands

Size is determined by REALIZED displayed amount, not linearly interpolated.

| Realized amount | Size band |
|---:|---:|
| 1–49 | 0.90x |
| 50–99 | 1.00x |
| 100–174 | 1.12x |
| 175–274 | 1.28x |
| 275–399 | 1.45x |
| 400+ | 1.62x |

This same amount-band system may be used for heal numbers; the color remains green.

## 3.3 Crisp rendering

Build/cache discrete raster variants for the six size bands.

Requirements:
- derive from the existing damage atlas;
- cache by semantic kind + size band;
- integer-aligned destination dimensions/positions where practical;
- avoid repeated fractional source scaling every frame;
- no soft shadowBlur over the glyph body;
- dark edge remains crisp;
- main fill remains solid/readable;
- no per-popup tint construction.

Do not fall back to generic Impact font during normal loaded gameplay.

## 3.4 Critical symbol and punch

A crit popup includes a compact ORANGE four-point manga burst/diamond immediately beside the number.

Do not rely on a Unicode star/font glyph.

Draw/cache the icon as simple canvas geometry using the crit palette.

Crit motion:
- begins at ~1.15x of its final band size;
- punches down to 1.0x over roughly 90ms;
- rises faster than normal damage;
- lifetime about 0.9s;
- may add a tiny local radial tick/burst;
- no giant full-screen flash.

For AUTO/SHOTGUN aggregation:
- keep one attack-total popup;
- if the attack context is critical, the aggregate popup is orange + crit mark.

# 4. MANGA BLOOD SPLATTER AUTHORITY

Target:
**manga impact blood — sharp directional spurts, tapered slash streaks, hard-edged droplets and a violent readable “toẹt” moment.**

No external asset is required for this pass.
Use existing `speckBlood.webp` only as one irregular alpha ingredient.

## 4.1 Blood palette

- wet/highlight blood: **#C62828**
- main blood: **#8F1218**
- dense/dried core: **#4A080C**
- deepest overlap: **#260407**

Do not use neon victim colors for persistent blood in this V3 style.

## 4.2 Transient manga spurt

On positive direct damage:
- 3–7 tapered directional streaks;
- 4–12 small droplets;
- direction follows impact force through/away from attacker;
- focused fan generally ±35 degrees;
- triangles/teardrops/irregular spear forms, not blurred lines;
- transient life ~120–220ms;
- hard edges, minimal/no blur.

Use normalized visual damage approximately:
`visualDamage = realizedDamage / ARSENAL_DAMAGE_SCALE`

Crit may increase footprint/density modestly (~1.15–1.25x), not 1.60x.

## 4.3 Persistent stain

Keep the accepted offscreen persistent stain canvas / one-composite-per-frame architecture.

A persistent hit stamp uses:
- one irregular speck/mask core;
- 2–5 tapered slash/spear streaks;
- 3–9 hard-edged satellite droplets;
- asymmetric directional composition;
- no perfect central ellipse.

Family language:
- SEMI: compact hard splash + one short fan;
- AUTO/BURST: many smaller ticks/specks, aggregate nearby hits;
- SHOTGUN/AUTOSHOT: wide directional fan of many narrow droplets;
- PRECISION: one strong long slash/spurt + small high-speed satellites;
- MELEE: curved slash/smear with thrown droplets;
- GRENADE/BLAST: radial starburst distribution.

No airbrushed puddle.
No capsule stain.
No giant opaque disk.
