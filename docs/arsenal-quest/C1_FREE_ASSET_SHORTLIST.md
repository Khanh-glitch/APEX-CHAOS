# ARSENAL QUEST C1 — FREE ASSET SHORTLIST (RESEARCHED 2026-09-24)

Purpose: shortlist free asset families that can support the locked Arsenal hybrid direction
(A tactical readability + B showmanship rhythm + C heavy impact) **before any large integration**.

Key principle:
**Do not treat downloaded assets as final 2D sprites. Prefer coherent CC0 3D source models,
then batch-render them into one custom 2D atlas with one orthographic camera, one light rig,
one outline treatment, one palette/material pass, and one anchor/orientation convention.**

That gives Arsenal a unified visual language even when source models come from several packs.

# RECOMMENDED ASSET PIPELINE

Do NOT integrate source pack PNGs directly.

1. Download candidate CC0 3D models.
2. Pick only the exact 12 Arsenal silhouettes.
3. Normalize scale/orientation in Blender.
4. Apply one Arsenal material palette:
   - graphite/dark body
   - steel/ivory edge
   - restrained class accent
5. Render with one orthographic camera and one three-light rig.
6. Add consistent outline / rim treatment.
7. Export transparent PNGs into a single Arsenal atlas.
8. Store original model + license/provenance separately.
9. In-game render uses only the generated 2D atlas.

This allows:
- guns + medieval weapons to look like one game;
- exact barrel/blade orientation;
- consistent visual scale;
- grenade sprite continuity;
- easy re-render if palette changes;
- no runtime 3D engine cost.
