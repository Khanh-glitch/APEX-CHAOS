# APEX CHAOS — Wave 2 Visual Promotion Gate

A Markdown spec is not sufficient to authorize production implementation.

For each surface, promotion to **GOLD VISUAL ACCEPTED** requires:

1. Canonical prototype source exists locally in this lane.
2. The source is self-contained/offline or has a documented dependency-localization path.
3. Owner has reviewed normal-scale behavior.
4. Desktop reference captured at 1366x768 and/or 1920x1080.
5. Mobile landscape reference captured near 844x390 with safe areas considered.
6. Mobile portrait reference captured near 390x844 with safe areas considered.
7. Primary interaction states are represented.
8. Reduced Motion behavior is specified or demonstrated.
9. Demo data is clearly non-authoritative.
10. Asset slots are declared.
11. No new gameplay/economy/lore system was invented merely for presentation.
12. Cross-surface audio policy is compatible with `GLOBAL_AUDIO_SETTINGS_AUTHORITY.md`.
13. Source hash/provenance is recorded after acceptance.
14. Implementation instruction explicitly says canonical-preserving transfer, not redesign.
