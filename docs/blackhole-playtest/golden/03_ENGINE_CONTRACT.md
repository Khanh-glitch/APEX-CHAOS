# ENGINE CONTRACT

## Golden parameter surface
The composer treats the following values as the reusable BLACK_HOLE visual vocabulary:

- `tension` — pre-event compression energy
- `K` — signed face-space collapse / rebound strength
- `rs` — event-horizon radius control
- `suck` — suction/trailing/capture intensity
- `stress` — outer-shell pressure lighting
- `band` — matter orbital speed
- `swirl` — log-polar forehead flow speed
- `twist` — log-polar shear / vortex character
- `eye` — rupture-eye emission
- `squint` — eye aperture tension
- `spin` — spacetime frame dragging
- `fall` — cosmic depth-flow direction/speed
- `growth` — composer-only whole-identity growth control
- `seatX`, `seatY` — composer-only singularity seat position

## Composition philosophy
A new skill should mostly be a **timeline over these controls**, plus a small amount of skill-specific geometry/data.

### A1 example
Entrance singularity = high `K`, `rs`, `suck`, `stress`, `swirl`, `spin`.
Exit event = reuse the same material/lens grammar but use an elastic/re-emission timeline rather than inventing a new portal style.

### A2 example
Absorb = medium horizon, lower suction, high stress, compressed motion.
Return = signed negative `K` / shock / flash / release impulse.

## Hard rule
If a skill requires replacing the cosmic material, rupture eyes, spacetime lens, or final composite just to look “different”, it is probably breaking hero cohesion rather than composing the engine.
