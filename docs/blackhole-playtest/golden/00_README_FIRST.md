# BLACK_HOLE_VFX_ENGINE

This package converts the lucky Opus 5.5 BLACK_HOLE artifact into a reusable visual system.

The key rule is: **future agents should compose with the proven code instead of recreating the look from prose.**

## Start here
1. Open `04_SKILL_COMPOSER_LAB.html`.
2. Compare it against `01_GOLDEN_BASELINE.html`.
3. Use the preset buttons to inspect how the exact same golden motion vocabulary can be recomposed for A1, A2 and passive growth.
4. Use MANUAL knobs to search for new choreography without touching the core shader language.

## What is preserved from the golden artifact
- cosmic interior
- rupture-eye construction
- torn matter sheets
- spacetime collapse / rebound mapping
- horizon/accretion/photon-ring language
- particle infall and tidal stretching
- spring choreography
- multi-level bloom + ACES final composite

## What this package is NOT
- not Apex production integration
- not final A1/A2 design authority
- not permission to rewrite BLACK_HOLE from scratch

It is a **visual engine + composition laboratory** so future models no longer need to rediscover Opus's good decisions by luck.
